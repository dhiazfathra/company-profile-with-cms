"There is exactly one Benefits section" is a true statement about the wrong noun.
The section is singular; the cards inside it are not, and it is the cards that the
schema has fixed at three.

The signal the skill teaches is the editor's question. "Change the headline" is a
global. "Add a fourth benefit" is a collection — and under this manifest that
request is a code change, which is the cost being hidden.

Note also what does _not_ count as evidence here: the model generates cleanly and
the section passes its fidelity check. Both are true and neither is about the
content model. A design that renders correctly today can still have frozen a
number the design will change.
