type: regex
target: last_message
pattern: '([Pp]ages not run|not run by this invocation|17 other|seventeen|other (?:17 )?pages|remaining pages)'
match: contains
matchExample: 'the "Pages not run by this invocation" section names the other 17 pages — this is evidence about Testimonial'
---

The correcting move has a name in the report: the section that lists the pages
this invocation did not target. An answer that praises the clean pass, or that
only suggests running `--all` "when there is time", never reaches the vocabulary
of scope. Several phrasings are accepted because the useful answer might quote the
section heading, count the untargeted pages, or simply say the remaining pages
were never run — all the same correction.
