The axis that catches this class of bug compares the render's shape against a
number taken from the design, so a bad reference image cannot make it lie. An
answer that never reaches it has only criticised.

The limit is deliberate: a keyword match cannot verify that _both_ comparison
axes are proposed, nor that the mention is positive rather than part of a
rejection. That requirement is carried by this case's `rejects-both.md` LLM
grader, whose criteria demands both axes plus a concrete alternative.
